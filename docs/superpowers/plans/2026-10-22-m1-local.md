## API contract
- GET /api/v1/auth/csrf → {headerName, token}; anonymous được gọi, no-store.
- POST /api/v1/auth/login (form username/password + CSRF) → {id, email, role}; sai → 401 JSON; không có public signup.
- GET /api/v1/auth/me → {id, email, role}; anonymous/expired → 401 JSON.
- POST /api/v1/auth/logout (+CSRF) → 204; hủy session.
- GET /api/v1/admin/access → {role}; OWNER/STAFF; GET /api/v1/admin/owner-access → OWNER only, STAFF → 403. Hai endpoint không expose dữ liệu khách và dùng cho foundation smoke.
- GET /actuator/health → status tối giản, endpoint actuator khác không public.

## Review focus / tests
CSRF login + token mới sau login/logout; session fixation/expiry; STAFF không được owner endpoint; inactive user không login; mật khẩu/bootstrap không ghi đè user có sẵn; SSR không gọi browser API; login lỗi không báo thành công hoặc điều hướng sai; unknown route 404.

## Deployment boundary
