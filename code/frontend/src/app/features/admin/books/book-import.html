Hướng dẫn các field

File cần đủ 20 cột bên dưới; cột không bắt buộc có thể để trống. Mỗi dòng là một biến thể, cùng nhom_sach là một sách và phải lặp lại cùng thông tin chung.

FieldCách nhập
nhom_sachBắt buộc. Khóa nhóm tự đặt, ví dụ A01; phân biệt hoa/thường, không phải mã MM.
ten_sach, ngon_nguBắt buộc. Tên sách và ngôn ngữ, ví dụ Tiếng Anh.
the_loai, kieu_biaThể loại bắt buộc; Picture book cần PAPERBACK hoặc HARDCOVER, thể loại khác để trống kiểu bìa.
gia_tu, gia_den, trong_luong_gBắt buộc. Giá nguyên VND, giá từ ≤ giá đến; trọng lượng gram nguyên dương. Không dùng dấu phân nhóm nghìn.
tinh_trang, mo_ta_tinh_trangBắt buộc. HIGH_FRESHNESS = Độ mới cao; MINOR_FLAWS = Có lỗi nhẹ. Mô tả rõ tình trạng/lỗi.
bien_the, ton_khoTồn bắt buộc, số nguyên 0–999999. Nhiều biến thể cần tên riêng khác nhau; một biến thể được để tên trống.
isbn, nha_xuat_ban, tac_gia, mo_ta_sachKhông bắt buộc. ISBN nhập dạng text để giữ số 0 đầu.
do_tuoi, trinh_do_doc, bo_suu_tap, link_videoKhông bắt buộc. Dùng mã bên dưới; nhiều độ tuổi/bộ sưu tập ngăn bằng dấu ;. Video là URL HTTPS.
